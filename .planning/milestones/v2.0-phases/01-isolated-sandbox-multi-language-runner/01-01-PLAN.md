<task type="auto">
  <name>Task 2: Linux cgroup v2 manager and network isolation controller</name>
  <files>packages/engine/src/cgroups.py, packages/engine/src/sandbox.py</files>
  <read_first>packages/engine/src/models.py</read_first>
  <action>
    Implement CgroupV2Manager in packages/engine/src/cgroups.py:
      - Detect cgroup v2 mount point (typically /sys/fs/cgroup)
      - Create transient cgroup scope path: /sys/fs/cgroup/cloudjudge/sub_{id}
      - Write memory.max = 268435456 (256MB)
      - Write cpu.max = 100000 100000 (100ms quota per 100ms period = 1 CPU)
      - Write pids.max = 64 to prevent fork bombs
      - Attach target PID to cgroup.procs
      - Read memory.peak and memory.events (oom_kill counter)
      - Provide clean teardown: kill lingering PIDs and rmdir transient scope
      - Provide automatic OS fallback when cgroup v2 is not available (e.g. macOS dev environment using setrlimit)
    Implement IsolationSandbox in packages/engine/src/sandbox.py:
      - Wraps subprocess execution inside transient cgroup
      - Drops network access using Linux unshare (CLONE_NEWNET) or unshare -n wrapper
      - Directs stdin, stdout, stderr through isolated pipes
  </action>
