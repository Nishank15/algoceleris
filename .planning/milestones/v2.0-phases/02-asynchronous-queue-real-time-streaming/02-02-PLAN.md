      - Constructor accepts QueueBroker and optional JudgeEvaluator
      - Event types:
        * 'compiling': emitted before compiler starts
        * 'compilation_failed': emitted if CE occurs
        * 'test_case_start': emitted before running test case N
        * 'test_case_result': emitted after test case N completes with time_ms, memory_bytes, verdict
        * 'completed': emitted with overall SubmissionReport
      - process_job(job_data: dict) -> SubmissionReport:
        1. Parse job payload into engine SubmissionJob and TestCase instances
        2. Publish compiling event to channel 'judge:events:{submission_id}'
        3. Hook runner/evaluator progress callbacks to stream per-testcase results
        4. Execute via JudgeEvaluator.evaluate()
        5. Publish terminal completed event with final report
        6. Store report in QueueBroker status store
      - run_once(queue_name: str, timeout: int = 1) -> bool:
        * Dequeue 1 job and process; return True if job was processed
      - run_forever(queue_name: str): Polling loop with graceful stop flag
  </action>
