  <action>
    1. Create `packages/gateway/src/subscriptions/models.py`:
       - `SubscriptionTier`: Enum `FREE = "free"`, `PRO = "pro"`.
       - `PaymentProvider`: Enum `STRIPE = "stripe"`, `RAZORPAY = "razorpay"`, `NONE = "none"`.
       - `SubscriptionRecord`: Pydantic model (`user_id`, `tier`, `provider`, `subscription_id`, `status`, `valid_until`, `created_at`).
       - `EntitlementResponse`: Pydantic model (`user_id`, `tier`, `can_use_ai_assistant`, `has_priority_queue`, `can_view_plagiarism_audit`, `rate_limit_per_minute`).
    2. Create `packages/gateway/src/subscriptions/store.py`:
       - `SubscriptionStore` interface with methods: `get_subscription(user_id)`, `set_subscription(user_id, record)`, `get_entitlements(user_id)`.
       - `InMemorySubscriptionStore` implementing default Free tier for all users and allowing setting Pro tier in memory.
       - `RedisSubscriptionStore` persisting user entitlement records under `user:subscription:{user_id}`.
    3. Create `packages/gateway/src/subscriptions/router.py`:
       - `GET /subscriptions/entitlements/{user_id}`: returns `EntitlementResponse`.
    4. Register subscription router under `/api/v1` in `packages/gateway/src/api.py`.
    5. Write unit tests in `packages/gateway/tests/test_subscriptions.py`:
       - Test default free tier entitlements.
       - Test updating to Pro tier grants `can_use_ai_assistant=True` and `has_priority_queue=True`.
       - Test entitlement endpoint response code and structure.
  </action>
  <verify>
