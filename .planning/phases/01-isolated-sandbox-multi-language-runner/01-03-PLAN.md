      - If javac exits non-zero: return ExecutionResult with verdict=ExecutionVerdict.COMPILATION_ERROR and stderr containing compilation errors

<task type="auto">
  <name>Task 2: JudgeEvaluator multi-testcase evaluation engine</name>
  <files>packages/engine/src/evaluator.py, packages/engine/src/__init__.py</files>
  <read_first>packages/engine/src/models.py, packages/engine/src/runners/base.py, packages/engine/src/comparator.py</read_first>
  <action>
    Implement JudgeEvaluator in packages/engine/src/evaluator.py:
      - Define SubmissionJob: submission_id: str, language: str ('cpp', 'python', 'java'), source_code: str, time_limit_ms: int, memory_limit_bytes: int, test_cases: List[TestCase]
      - Define TestCase: id: int, input_data: str, expected_output: str, is_sample: bool = False
      - Define TestCaseResult: test_case_id: int, verdict: ExecutionVerdict, execution_time_ms: int, memory_used_bytes: int, stdout: str, stderr: str
      - Define SubmissionReport: submission_id: str, verdict: ExecutionVerdict, test_cases_passed: int, total_test_cases: int, max_time_ms: int, max_memory_bytes: int, test_case_results: List[TestCaseResult], compile_output: Optional[str]
      - Execution logic:
        1. Select appropriate runner (CppRunner, PythonRunner, JavaRunner) based on language string
        2. Compile once if language requires compilation (C++, Java). If compilation fails, return SubmissionReport with COMPILATION_ERROR immediately
        3. Loop over test cases sequentially, running binary/script against each test case input
        4. Validate stdout using OutputComparator against expected_output
        5. Stop on first non-accepted test case (short-circuit) or collect all results
        6. Aggregate overall verdict (ACCEPTED if all pass, else the first failing verdict)
        7. Clean up compilation binaries and temporary workspaces
  </action>

    <automated>python3 -m unittest discover -s packages/engine/tests -p "test_evaluator.py"</automated>
