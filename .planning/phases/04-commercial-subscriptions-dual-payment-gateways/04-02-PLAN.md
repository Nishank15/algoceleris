         - Method `create_checkout_session(user_id: str, email: str, success_url: str, cancel_url: str) -> Dict[str, Any]`:
           - Returns checkout session ID and checkout URL (e.g. `cs_test_{uuid}`).
         - Method `verify_webhook_signature(payload: bytes, signature_header: str, webhook_secret: str) -> bool`:
           - Cryptographically verifies Stripe `v1` HMAC-SHA256 signature using `hmac.compare_digest(computed_sig, signature_v1)`.
         - Method `handle_webhook_event(event_data: Dict[str, Any], store: SubscriptionStore) -> Dict[str, Any]`:

           - On `customer.subscription.deleted`: sets user tier back to `free`.
    2. Write unit tests in `packages/gateway/tests/test_stripe_integration.py`:
       - Verify checkout session returns valid session payload with `checkout_url`.
       - Test signature verification with valid and corrupted signatures.
       - Test `checkout.session.completed` provisions Pro entitlement.
       - Test `customer.subscription.deleted` revokes Pro entitlement.
