  <action>
    1. Create `packages/gateway/src/subscriptions/razorpay_service.py`:
       - `RazorpayService` class:
         - Method `create_order(user_id: str, email: str, amount_paise: int = 149900, currency: str = "INR") -> Dict[str, Any]`:
           - Returns Razorpay order payload (`id`: `order_{uuid[:14]}`, `amount`: 149900, `currency`: "INR", `receipt`: `rcpt_{user_id}`).
         - Method `verify_payment_signature(order_id: str, payment_id: str, signature: str, secret: str) -> bool`:
           - Computes `hmac.new(secret.encode(), f"{order_id}|{payment_id}".encode(), hashlib.sha256).hexdigest()`.
           - Returns `hmac.compare_digest(generated_signature, signature)`.
         - Method `verify_webhook_signature(payload: bytes, signature_header: str, secret: str) -> bool`:
           - Verifies `X-Razorpay-Signature` against body HMAC-SHA256.
         - Method `fulfill_payment(user_id: str, order_id: str, payment_id: str, store: SubscriptionStore) -> Dict[str, Any]`:
           - Sets user tier to `pro`, sets payment provider to `razorpay`, records payment ID and timestamp.
    2. Write unit tests in `packages/gateway/tests/test_razorpay_integration.py`:
       - Test order creation returns expected INR amount (149900 paise = ₹1,499).
       - Test HMAC signature verification matches authentic signatures and rejects modified payloads.
       - Test webhook signature verification.
       - Test payment fulfillment upgrades user to Pro tier.
  </action>
