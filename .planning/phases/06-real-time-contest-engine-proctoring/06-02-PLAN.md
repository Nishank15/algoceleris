  <action>
    1. Create `packages/gateway/src/contests/leaderboard.py`:
       - `LeaderboardEntry`: Pydantic model (`rank: int`, `user_id: str`, `solved_count: int`, `total_penalty_minutes: int`, `problem_scores: Dict[str, dict]`, `score_composite: float`).
       - `LeaderboardEngine`:
         - Score formula: `composite_score = (solved_count * 1_000_000_000) - (total_penalty_minutes * 60)`.
         - Methods:
           * `record_score(contest_id: str, participant: ParticipantScore) -> int (new rank)`
           * `get_leaderboard(contest_id: str, limit: int = 100) -> List[LeaderboardEntry]`
           * `get_user_rank(contest_id: str, user_id: str) -> Optional[int]`
         - Backends:
           * `RedisLeaderboardBackend`: Uses Redis `ZADD`, `ZREVRANGE`, `ZREVRANK`, `ZSCORE`.
           * `InMemoryLeaderboardBackend`: Thread-safe sorted dict for unit tests and local execution.
    2. Write unit tests in `packages/gateway/tests/test_contest_leaderboard.py`:
       - Test participant with more solves ranks higher regardless of penalty.
       - Test participants with equal solves are tie-broken by lower penalty.
       - Test updating participant score recalculates rank instantly.
  </action>
