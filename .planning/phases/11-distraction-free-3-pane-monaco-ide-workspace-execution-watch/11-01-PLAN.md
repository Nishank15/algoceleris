       - Implement a 10-second execution watchdog timer ref (`watchdogTimerRef`):
         * When `executeSubmission()` starts, set a 10,000ms timer.
         * If the submission does not resolve to `COMPLETED` or `FAILED` within 10,000ms:
           - Automatically abort/unsubscribe the active WebSocket stream.
           - Set `isRunning(false)`.
           - Set `submissionStatus('FAILED')`.
           - Set `errorDiagnostics` with explicit watchdog warning:
             `"Execution Watchdog: Sandbox evaluation timed out after 10.0s without receiving a terminal verdict. The judge worker or queue may be congested."`
         * When a terminal stream event (`completed` or `compilation_failed`) or error occurs within 10s, clear `watchdogTimerRef`.
       - Clean up `watchdogTimerRef` on component unmount.
    2. Synchronize solved state:
       - When a submission report arrives with `report.verdict === 'ACCEPTED'`, call `markProblemSolved(activeProblemId)`.
       - When a submission report arrives with any non-accepted verdict, call `markProblemAttempted(activeProblemId)`.
  </action>
