## 3. Cross-Phase Integration & End-to-End User Flows

1. **Discovery & Exploration Flow (Phase 8 + Phase 9 + Phase 10)**:
   - Visitor navigates to `/` → explores live micro-sandbox runner teaser and platform telemetry.
   - Visitor clicks "Explore Problems" or header navigation → transitions smoothly to `/problems`.
   - Filters problems by algorithmic tags (e.g. `Dynamic Programming`) or difficulty pills in sub-50ms.

2. **Solving & Evaluation Flow (Phase 10 + Phase 11)**:
   - Visitor selects a problem (e.g. *Two Sum*) → navigates to `/problems/two-sum`.
   - Monaco IDE loads standard `class Solution` template with VS Code Dark Modern syntax highlighting.
   - Visitor runs code → real-time streaming feedback; 10-second watchdog protects against hung connections.
   - Testcase console renders side-by-side token diff if output does not match expected output.
   - Successful submission marks problem solved in `problemService.ts` (`localStorage`).

3. **Developer Analytics & Gamification Flow (Phase 11 + Phase 12)**:
   - Solved problems instantly sync into the Developer Profile at `/u/developer`.
   - Hero card updates Solved Difficulty breakdown ring and submission history log.
   - Contribution Activity skyline renders 2D/3D toggleable heatmap with orbit controls.

4. **Competition Flow (Phase 8 + Phase 12)**:
   - User navigates to `/contests` → views live and upcoming contests with ticking countdown timers.
   - User clicks "Register" → button reflects persistent registration status.
   - User clicks "View Leaderboard" → enters full-page leaderboard with live Redis Sorted Set rankings and problem score matrix.
