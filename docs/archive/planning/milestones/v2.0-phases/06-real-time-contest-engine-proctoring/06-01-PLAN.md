<task type="tracer">
  <name>Task 1: Tracer slice — Contest models and ICPC penalty scoring algorithm</name>
  <files>packages/gateway/src/contests/__init__.py, packages/gateway/src/contests/models.py, packages/gateway/src/contests/scoring.py, packages/gateway/tests/test_contest_engine.py</files>
  <read_first>packages/gateway/src/models.py</read_first>
  <action>
    1. Create `packages/gateway/src/contests/models.py`:
       - `ContestStatus`: Enum (`UPCOMING`, `ACTIVE`, `ENDED`).
       - `ContestProblem`: Pydantic model (`id`, `letter_code` e.g. "A", "B", "C", `title`, `difficulty`, `points`).
       - `Contest`: Pydantic model (`id`, `title`, `description`, `start_time`, `end_time`, `duration_minutes`, `status`, `problems: List[ContestProblem]`).
       - `ProblemScore`: Pydantic model (`problem_id`, `solved: bool`, `rejected_attempts: int`, `solved_at_minute: Optional[int]`, `penalty_minutes: int`).
       - `ParticipantScore`: Pydantic model (`user_id`, `contest_id`, `solved_count: int`, `total_penalty_minutes: int`, `problem_scores: Dict[str, ProblemScore]`, `registered_at: float`).
       - `ContestSubmissionRequest`: Pydantic model (`user_id`, `problem_id`, `language`, `source_code`).
       - `ContestSubmissionResponse`: Pydantic model (`submission_id`, `contest_id`, `problem_id`, `verdict`, `score_delta: dict`).
    2. Create `packages/gateway/src/contests/scoring.py`:
       - `ICPCScoringEngine`:
         - Method `process_submission(participant: ParticipantScore, problem_id: str, verdict: str, submission_time: float, contest_start_time: float) -> ParticipantScore`.
         - If problem already solved by user, return without modifying penalty.
         - If verdict is `ACCEPTED`:
           * Mark `solved = True`.
           * Set `solved_at_minute = max(1, int((submission_time - contest_start_time) / 60))`.
           * Calculate penalty: `penalty = solved_at_minute + (rejected_attempts * 20)`.
           * Recalculate participant `solved_count` and `total_penalty_minutes`.
         - If verdict is non-accepted (`WRONG_ANSWER`, `TIME_LIMIT_EXCEEDED`, `RUNTIME_ERROR`, `MEMORY_LIMIT_EXCEEDED`):
           * Increment `rejected_attempts += 1`.
    3. Write unit tests in `packages/gateway/tests/test_contest_engine.py`:
       - Test single AC with 0 prior rejections has penalty equal to minute of submission.
       - Test rejected submissions increment attempts and contribute 20 minutes penalty each once AC is achieved.
       - Test submissions after AC are ignored.
       - Test never-accepted problems do not add penalty.
  </action>
  <verify>
    <command>python3 -m unittest packages/gateway/tests/test_contest_engine.py</command>
    <expected_output>All scoring engine tests pass.</expected_output>
  </verify>
</task>
