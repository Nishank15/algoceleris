<task type="vertical_slice">
  <name>Task 2: Vertical slice — Winnowing / MOSS fingerprinting algorithm</name>
  <files>packages/gateway/src/plagiarism/winnowing.py, packages/gateway/tests/test_plagiarism.py</files>
  <read_first>packages/gateway/src/plagiarism/ast_parser.py</read_first>
  <action>
    1. Create `packages/gateway/src/plagiarism/winnowing.py`:
       - `WinnowingEngine`:
         * Configurable parameters: $k$-gram size (default $k=5$), window size $w$ (default $w=4$).
         * Hashes each $k$-gram using a 64-bit rolling hash or cryptographic digest.
         * Applies sliding window of size $w$ to pick the minimum hash value (Winnowing algorithm guarantee: any match of length $\ge w + k - 1$ is guaranteed to share a fingerprint).
         * Returns set of `(hash_value, position)` fingerprints.
         * Jaccard similarity and containment coefficient calculation:
           $$\text{similarity}(A, B) = \frac{2 \times |F_A \cap F_B|}{|F_A| + |F_B|}$$
    2. Update `packages/gateway/tests/test_plagiarism.py`:
       - Test identical code yields 1.0 (100%) similarity.
       - Test renamed code yields near 1.0 similarity.
       - Test completely different code yields low similarity (< 0.20).
       - Test sliding window bounds guarantee.
  </action>
  <verify>
    <command>python3 -m unittest packages/gateway/tests/test_plagiarism.py</command>
    <expected_output>Winnowing fingerprinting tests pass.</expected_output>
  </verify>
</task>
