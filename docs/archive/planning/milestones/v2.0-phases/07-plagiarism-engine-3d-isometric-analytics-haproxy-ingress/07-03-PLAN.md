  <name>Task 1: Tracer slice — Production HAProxy Layer 7 configuration</name>
  <files>deploy/haproxy/haproxy.cfg</files>
  <read_first>packages/gateway/src/main.py</read_first>
  <action>
    1. Create `deploy/haproxy/haproxy.cfg`:
       - Global and defaults:
         * `mode http`, `maxconn 4096`, `timeout connect 5s`, `timeout client 50s`, `timeout server 50s`, `timeout tunnel 3600s`.
       - Frontend `ingress_http`:
         * Bind `0.0.0.0:80` (and `0.0.0.0:8080`).
         * Header normalization: `option forwardfor`, `http-request add-header X-Forwarded-Proto https if { ssl_fc }`.
         * WebSocket ACLs:
           `acl is_websocket hdr(Upgrade) -i WebSocket`
           `acl is_ws_path path_beg /ws/`
         * Routing rules:
           `use_backend gateway_ws_cluster if is_websocket or is_ws_path`
           `default_backend gateway_api_cluster`
       - Backend `gateway_api_cluster`:
         * `balance roundrobin`
         * `option httpchk GET /health`
         * `http-check expect status 200`
         * Cluster nodes: `gateway_1:8000 check inter 2s fall 3 rise 2`, `gateway_2:8000 check inter 2s fall 3 rise 2`.
       - Backend `gateway_ws_cluster`:
         * `balance leastconn`
         * `timeout tunnel 3600s`
         * Cluster nodes: `gateway_1:8000 check inter 2s`, `gateway_2:8000 check inter 2s`.
       - Admin stats listener:
         * Bind `0.0.0.0:8404`, stats enabled at `/stats`, refresh interval 5s.
  </action>
  <verify>
    <command>python3 -c "import re; data=open('deploy/haproxy/haproxy.cfg').read(); assert 'backend gateway_api_cluster' in data and 'backend gateway_ws_cluster' in data and 'timeout tunnel' in data; print('HAProxy cfg verified')"</command>
    <expected_output>HAProxy cfg verified</expected_output>
  </verify>
