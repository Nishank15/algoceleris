## 3. Cross-Phase Integration & End-to-End User Flows

1. **User Registration & Availability Flow (Phase 13 + Phase 14 + Phase 16)**:
   - Prospective user enters username and email on `/auth/signup`.
   - Frontend triggers debounced (150ms) availability checks against `POST /api/v1/auth/check-username` and `check-email`.
   - Gateway tests candidate availability against RedisBloom filter with sub-millisecond response time before querying PostgreSQL `users` table.
   - User inputs password, which is hashed using Argon2id (`time_cost=2`, `memory_cost=65536`).
   - Account is created in PostgreSQL `users`, Bloom filters are populated (`BF.ADD`), and dual tokens (15m JWT + 7d rotating HttpOnly refresh cookie) are issued.

2. **Guest Work History Migration Flow (Phase 13 + Phase 16)**:
   - Anonymous visitor solves problems without logging in; submissions are tracked in browser `localStorage`.
   - Visitor signs up or logs in.
   - `useGuestMigration` hook detects local submissions and sends payload to `POST /api/v1/users/submissions/migrate-guest`.
   - Gateway associates all anonymous records with the authenticated user ID and stores them in PostgreSQL `submissions` table atomically.
   - Local submission cache is cleared, and user's profile immediately reflects past practice activity.

3. **Entitlements, AI Protection & Admin Governance Flow (Phase 14 + Phase 15)**:
   - Free user attempts to run Gemini AI assistant debugging (`POST /api/v1/ai/debug`).
   - `require_pro` dependency intercepts the request and verifies the user's role in the JWT token and database.
   - Request is rejected with HTTP 403 and body `{"required_tier": "pro", "code": "TIER_RESTRICTED"}`.
   - Frontend intercepts 403 and opens `PricingModal` to allow Stripe or Razorpay checkout.
   - Platform administrator can run `python -m src.cli set-role <username> admin` to grant admin rights with immunity against third-party billing cancellation.

4. **Live Database Analytics & 3D Skyline Flow (Phase 13 + Phase 16)**:
   - User navigates to `/u/:username`.
   - `ProfilePage` queries `GET /api/v1/users/:username/analytics` and `GET /api/v1/users/:username/submission-activity`.
   - Gateway aggregates distinct solved problems by difficulty (Easy, Medium, Hard) and computes contest rating history directly from `submissions` and `contest_participations`.
   - Profile renders live SVG difficulty rings, rating sparkline, and the 21st.dev `IsometricHeatmap` skyline with daily contribution bars.

5. **Universal Theme Inversion Flow (Phase 17 across all pages)**:
   - User clicks `#nav-theme-toggle` in `LinearHeaderNav`.
   - `ThemeContext` updates `data-theme` attribute on `<html>` and persists preference in `localStorage.cloud_judge_theme`.
   - CSS token inversion immediately re-skins background, surfaces, borders, and typography to Linear Light without page reload.
   - Monaco editor reactively invokes `monaco.editor.setTheme('vs')` without unmounting the editor buffer or resetting the cursor.
   - `IsometricHeatmap` MutationObserver detects `data-theme` changes and switches its 3D canvas shaders to light mode.
