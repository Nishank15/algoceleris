<task type="auto">
  <name>Task 3: Implement Async Connection Pool Engine</name>
  <files>packages/gateway/src/database.py</files>
  <read_first>packages/gateway/src/queue.py</read_first>
  <action>
Create `packages/gateway/src/database.py`:
1. Define `Base = declarative_base()` (or `class Base(DeclarativeBase): pass` in SQLAlchemy 2.0 style).
2. Configure settings/env resolution:
   - `DATABASE_URL`: default to `os.getenv("DATABASE_URL", "postgresql+asyncpg://postgres:postgres@localhost:5432/cloud_judge")`.
   - `DB_POOL_SIZE`: default `int(os.getenv("DB_POOL_SIZE", "10"))`.
   - `DB_MAX_OVERFLOW`: default `int(os.getenv("DB_MAX_OVERFLOW", "20"))`.
   - `DB_POOL_TIMEOUT`: default `float(os.getenv("DB_POOL_TIMEOUT", "30.0"))`.
   - `USE_IN_MEMORY_DB`: support `sqlite+aiosqlite:///:memory:` fallback if `DATABASE_URL` is set to sqlite or test flag is active.
3. Define `get_async_engine(db_url: Optional[str] = None)`:
   - Cache singleton async engine instance using `create_async_engine`.
   - Set `pool_size=DB_POOL_SIZE`, `max_overflow=DB_MAX_OVERFLOW`, `pool_timeout=DB_POOL_TIMEOUT`, `pool_pre_ping=True`.
4. Define `get_session_factory(engine=None)` returning `async_sessionmaker(bind=engine, expire_on_commit=False)`.
5. Provide FastAPI dependency `async def get_db() -> AsyncGenerator[AsyncSession, None]`:
   - Yields session, handles rollback on exception, closes cleanly in finally.
6. Provide async health check function `async def check_db_health(engine=None) -> Dict[str, Any]`:
   - Executes `SELECT 1` via `connection.execute(text("SELECT 1"))`.
   - Returns `{"status": "healthy", "database": "connected"}` or `{"status": "unhealthy", "error": str(exc)}`.
  </action>
  <verify>python3 -c "from packages.gateway.src.database import Base, get_async_engine, check_db_health; print('database module loaded successfully')"</verify>
  <acceptance_criteria>
    - packages/gateway/src/database.py defines DeclarativeBase Base
    - packages/gateway/src/database.py defines get_async_engine with pool_pre_ping=True
    - packages/gateway/src/database.py defines get_db async session dependency
    - packages/gateway/src/database.py defines check_db_health executing SELECT 1
  </acceptance_criteria>
  <done>Async database module provides connection pooling, session dependency, and health checking</done>
</task>
