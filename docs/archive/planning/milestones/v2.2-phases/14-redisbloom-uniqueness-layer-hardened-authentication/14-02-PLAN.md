<task type="auto">
  <name>Task 2: Implement FastAPI Auth Router with Dual-Token Rotation</name>
  <files>packages/gateway/src/auth/router.py, packages/gateway/src/auth/__init__.py</files>
  <read_first>packages/gateway/src/auth/security.py, packages/gateway/src/auth/bloom.py, packages/gateway/src/database.py</read_first>
  <action>
Create `packages/gateway/src/auth/router.py`:
1. Implement `create_auth_router(bloom_checker=None, redis_client=None) -> APIRouter`:
   - Router prefix: `/api/v1/auth` (or `/auth` when included in api_router).
   - Dependencies: `get_db` async session generator.
2. Endpoint `POST /signup`:
   - Checks `is_username_available` and `is_email_available` using Bloom checker + DB fallback.
   - If not available, raises HTTP 409 Conflict with detail indicating which field is taken.
   - Hashes password using Argon2id.
   - Creates and commits `User` record in PostgreSQL.
   - Adds username and email to RedisBloom.
   - Generates access token (15m) and refresh token (14d).
   - Registers refresh token family in Redis.
   - Sets HttpOnly cookie: `response.set_cookie(key="refresh_token", value=refresh_token, httponly=True, samesite="lax", max_age=14*86400, secure=False)`. (Secure=True if HTTPS).
   - Returns `TokenResponse` with `access_token` and `user`.
3. Endpoint `POST /login`:
   - Queries `User` by matching `lower(username)` or `lower(email)`.
   - Verifies password with Argon2id. If invalid, raises HTTP 401 Unauthorized ("Invalid credentials").
   - Generates access token and new refresh token family.
   - Sets HttpOnly refresh cookie.
   - Returns `TokenResponse`.
4. Endpoint `POST /refresh`:
   - Reads `refresh_token` from cookie (or header).
   - Decodes token, validates claims and family in Redis.
   - If replay detected (token was already cycled): revokes family and raises HTTP 401 ("Token reuse detected, session revoked").
   - Fetches current user from PostgreSQL to ensure account is active and has fresh role/tier.
   - Generates new access token and cycles refresh token in the same family.
   - Updates HttpOnly cookie with new refresh token.
   - Returns `TokenResponse`.
5. Endpoint `POST /logout`:
   - Reads refresh token, revokes in Redis, deletes HttpOnly cookie.
   - Returns `{"message": "Logged out successfully"}`.
6. Endpoint `GET /me`:
   - Extracts Bearer token from `Authorization` header.
   - Validates access token, queries user record from DB, returns `UserResponse`.
7. Endpoint `GET /check-availability`:
   - Query params: `username: Optional[str]`, `email: Optional[str]`.
   - Returns `AvailabilityResponse` with `available: true/false`.
  </action>
