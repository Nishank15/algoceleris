<task type="auto">
  <name>Task 1: Implement RBAC Route Guards in Gateway Auth Module</name>
  <files>packages/gateway/src/auth/rbac.py, packages/gateway/src/auth/__init__.py</files>
  <read_first>packages/gateway/src/auth/security.py, packages/gateway/src/database.py, packages/gateway/src/models/entities.py</read_first>
  <action>
Create `packages/gateway/src/auth/rbac.py`:
1. `get_current_user`:
   - FastAPI dependency extracting `Authorization: Bearer <token>` from request header.
   - If missing, raises `HTTPException(status_code=401, detail="Authentication token required", headers={"WWW-Authenticate": "Bearer"})`.
   - Decodes token via `decode_token(token)`.
   - Validates token `type == "access"`.
   - Queries `User` entity from PostgreSQL database via `db: AsyncSession = Depends(get_db)`.
   - If user not found, raises `HTTPException(status_code=401, detail="User account not found")`.
   - Returns authenticated `User` object.
2. `get_optional_current_user`:
   - FastAPI dependency checking for optional `Authorization: Bearer <token>`.
   - If token is missing or invalid, returns `None` (for guest/public endpoints that customize behavior when authenticated).
   - If token is valid, returns authenticated `User` object.
3. `require_pro`:
   - FastAPI dependency depending on `get_current_user`.
   - Checks if `user.account_type in ("pro", "admin")`.
   - If satisfied, returns the authenticated `user`.
   - If not satisfied (`user.account_type == "free"`), raises `HTTPException(status_code=403, detail={"error": "pro_tier_required", "message": "Pro subscription required", "upgrade_url": "/pricing", "current_tier": user.account_type})`.
4. `require_admin`:
   - FastAPI dependency depending on `get_current_user`.
   - Checks if `user.account_type == "admin"`.
   - If satisfied, returns the authenticated `user`.
   - If not satisfied, raises `HTTPException(status_code=403, detail={"error": "admin_privileges_required", "message": "Administrative privileges required"})`.
5. Export `get_current_user`, `get_optional_current_user`, `require_pro`, `require_admin` in `packages/gateway/src/auth/__init__.py`.
  </action>
  <verify>python3 -c "from packages.gateway.src.auth.rbac import get_current_user, require_pro, require_admin; print('RBAC dependencies imported successfully')"</verify>
</task>

  <name>Task 2: Implement Admin CLI Subcommand for Role Management</name>
  <files>packages/gateway/src/cli.py</files>
  <read_first>packages/gateway/src/cli.py, packages/gateway/src/models/entities.py, packages/gateway/src/subscriptions/store.py</read_first>
  <action>
Update `packages/gateway/src/cli.py`:
1. Implement `run_set_role(email: Optional[str] = None, username: Optional[str] = None, role: str = "pro", db_url: Optional[str] = None, redis_url: Optional[str] = None) -> bool`:
   - Validates `role.lower()` is in `{"free", "pro", "admin"}`. Raises ValueError if invalid.
   - Requires at least one of `email` or `username`.
   - Queries `User` in PostgreSQL by `email` (case-insensitive) or `username` (case-insensitive).
   - If user not found, logs error and returns False.
   - Updates `user.account_type = role.lower()`.
   - Commits session.
   - Also syncs `SubscriptionStore` (in Redis or in-memory) for the user's `id` to match the new role:
     - `pro` or `admin` -> `SubscriptionTier.PRO`, `status="active"`
     - `free` -> `SubscriptionTier.FREE`, `status="canceled"`
   - Logs `INFO: Successfully updated user '{user.username}' ({user.email}) role from '{old_role}' to '{role}'`.
   - Returns True.
2. In `main()` of `cli.py`:
   - Register `set-role` subparser:
     - `--email`: User email address
     - `--username`: User username
     - `--role`: Target role (`free`, `pro`, `admin`) (required)
     - `--db-url`: Optional database URL override
     - `--redis-url`: Optional Redis URL override
   - Dispatch `set-role` subcommand to `asyncio.run(run_set_role(...))`.
   - Exit with code 0 on success, code 1 on failure.
  </action>
  <verify>python3 -m packages.gateway.src.cli --help</verify>
