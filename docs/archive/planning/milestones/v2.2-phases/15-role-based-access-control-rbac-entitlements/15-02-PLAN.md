  <files>packages/gateway/src/subscriptions/db_sync.py, packages/gateway/src/subscriptions/__init__.py</files>

  <action>
Create `packages/gateway/src/subscriptions/db_sync.py`:
1. Implement `sync_stripe_event_to_db(db: AsyncSession, event: Dict[str, Any], store: Optional[SubscriptionStore] = None) -> Dict[str, Any]`:
   - Extracts `event_type = event.get("type", "")` and `data_obj = event.get("data", {}).get("object", {})`.
   - Resolves user:
     - Check `client_reference_id` or `metadata.user_id` or query by `customer_email` or `customer` ID.
     - Supports UUID strings or username/email resolution.
   - For activation events (`checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `invoice.payment_succeeded`):
     - Extracts `customer_id`, `subscription_id`, `current_period_end` (converts Unix timestamp to datetime with UTC timezone).
     - Finds `User` in DB. If `user.account_type != "admin"`, sets `user.account_type = "pro"`.
     - Upserts `Subscription` record:
       - Query existing `Subscription` where `provider == "stripe"` and `user_id == user.id`.
       - If exists, update `status = "active"`, `subscription_id`, `customer_id`, `current_period_end`, `updated_at`.
       - If not exists, insert new `Subscription(user_id=user.id, provider="stripe", customer_id=customer_id, subscription_id=subscription_id, status="active", current_period_end=current_period_end)`.
     - Also updates `store.set_subscription(...)` if store is provided.
     - Commits DB transaction.
     - Returns `{"status": "provisioned", "user_id": str(user.id), "tier": "pro"}`.
   - For cancellation / lapse events (`customer.subscription.deleted`, `customer.subscription.cancelled`, `invoice.payment_failed`):
     - Finds `User` in DB.
     - If `user.account_type != "admin"`, sets `user.account_type = "free"`. (Administrative accounts are immune to demotion).
     - Finds `Subscription` record where `provider == "stripe"` and `user_id == user.id` (or matching `subscription_id`):
       - Sets `status = "canceled"` (or "past_due" for payment failure).
     - Also updates `store.set_subscription(...)` if store is provided.
     - Commits DB transaction.
     - Returns `{"status": "downgraded", "user_id": str(user.id), "tier": "free"}`.
2. Implement `sync_razorpay_payment_to_db(db: AsyncSession, user_id: str, order_id: str, payment_id: str, store: Optional[SubscriptionStore] = None) -> Dict[str, Any]`:
   - Resolves user by UUID or username/email.
   - Finds `User` in DB. If `user.account_type != "admin"`, sets `user.account_type = "pro"`.
   - Computes `current_period_end = datetime.now(timezone.utc) + timedelta(days=30)`.
   - Upserts `Subscription` record:
     - Query existing `Subscription` for `provider == "razorpay"` and `user_id == user.id`.
     - Update or insert with `provider="razorpay"`, `subscription_id=payment_id`, `status="active"`, `current_period_end=current_period_end`.
   - Also updates `store.set_subscription(...)` if store is provided.
   - Commits DB transaction.
   - Returns `{"status": "provisioned", "user_id": str(user.id), "tier": "pro", "provider": "razorpay"}`.
3. Export `sync_stripe_event_to_db` and `sync_razorpay_payment_to_db` in `packages/gateway/src/subscriptions/__init__.py`.
  </action>
