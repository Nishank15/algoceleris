<task type="auto">
  <name>Task 2: Implement User Analytics & Guest Migration Router</name>
  <files>packages/gateway/src/users/router.py, packages/gateway/src/api.py</files>
  <read_first>packages/gateway/src/models/entities.py, packages/gateway/src/auth/rbac.py, packages/gateway/src/database.py, packages/gateway/src/api.py</read_first>
  <action>
Create `packages/gateway/src/users/router.py` with `create_users_router()`:
1. `GET /api/v1/users/{username}/profile`:
   - Resolve `User` by username (`func.lower(User.username) == username.lower()`).
   - If user not found, raise `HTTPException(status_code=404, detail="User not found")`.
   - **Difficulty Breakdown (`UX-03`)**:
     - Query distinct `problem_slug` with `verdict = 'ACCEPTED'` and `user_id = user.id`.
     - Cross-reference known problem difficulties (from predefined mapping matching frontend constants: e.g. two-sum: Easy, reverse-string: Easy, palindrome-number: Easy, valid-anagram: Easy, fizz-buzz: Easy, max-subarray: Medium, longest-substring: Medium, lru-cache: Medium, coin-change: Medium, merge-intervals: Medium, trapping-rain-water: Hard, median-two-sorted-arrays: Hard, word-ladder: Hard, n-queens: Hard, edit-distance: Hard). Fall back to 'Medium' if unknown slug.
     - Calculate totals and solved counts for Easy, Medium, Hard.
   - **Contest Progression (`UX-04`)**:
     - Query `ContestParticipation` for `user_id = user.id` ordered by `created_at ASC`.
     - Calculate cumulative rating starting at default 1500 + sum(`rating_delta`).
     - Produce list of `ContestRatingPoint`. If empty, provide baseline or empty history.
   - **Daily Skyline Submissions (`UX-05`)**:
     - Query submissions grouped by `func.date(Submission.created_at)` for `user_id = user.id` within the past 365 days.
     - Format results as `[DailyContributionPoint(date=d, count=c)]`.
   - Return structured `UserProfileResponse`.
2. `POST /api/v1/users/submissions/migrate-guest` (`UX-02`):
   - Dependency: `current_user: User = Depends(get_current_user)` (requires Bearer JWT).
   - Ingests `req: MigrateGuestRequest`.
   - Bulk creates `Submission` records with `user_id = current_user.id`.
   - Sets `created_at` from item `created_at` (parsed from ISO or defaulting to UTC now).
   - Commits records to PostgreSQL session.
   - Returns `MigrateGuestResponse(migrated_count=len(created), message=f"Successfully migrated {len(created)} submissions")`.
3. In `packages/gateway/src/api.py`:
   - Import `create_users_router`.
   - Mount router on `api_router.include_router(users_router)`.
  </action>
  <verify>python3 -c "from packages.gateway.src.users.router import create_users_router; print('Users router created successfully')"</verify>
</task>
