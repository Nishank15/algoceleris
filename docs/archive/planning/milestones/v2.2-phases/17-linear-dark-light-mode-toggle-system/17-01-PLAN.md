<task type="auto">
  <name>Task 1: Create ThemeContext with Persistence and System Fallback</name>
  <files>packages/frontend/src/context/ThemeContext.tsx, packages/frontend/src/App.tsx</files>
  <read_first>packages/frontend/src/App.tsx, packages/frontend/src/context/AuthContext.tsx</read_first>
  <action>
1. Create `packages/frontend/src/context/ThemeContext.tsx`:
   - Define type `Theme = 'dark' | 'light'`.
   - Define interface `ThemeContextType { theme: Theme; toggleTheme: () => void; setTheme: (theme: Theme) => void }`.
   - Storage key constant: `THEME_STORAGE_KEY = 'cloud_judge_theme'`.
   - Initializer function:
     - Check `localStorage.getItem(THEME_STORAGE_KEY)`; if `'dark'` or `'light'`, return it.
     - Fallback: Check `window.matchMedia && window.matchMedia('(prefers-color-scheme: light)').matches ? 'light' : 'dark'`.
     - Default: `'dark'`.
   - In `ThemeProvider`:
     - Synchronize `document.documentElement.setAttribute('data-theme', theme)` whenever `theme` changes.
     - Synchronize `document.documentElement.classList.toggle('light', theme === 'light')`.
     - Persist `localStorage.setItem(THEME_STORAGE_KEY, theme)`.
     - Add `change` listener to `window.matchMedia('(prefers-color-scheme: light)')` so that if no manual override is set in `localStorage`, OS mode switches update state automatically.
     - Export `useTheme(): ThemeContextType`.
2. In `packages/frontend/src/App.tsx`:
   - Wrap `<BrowserRouter>` inside `<ThemeProvider>`.
  </action>
  <verify>npm --prefix packages/frontend run build</verify>
</task>
